# user-crud

Aplicação simples para demonstrar um CRUD (Create, Read, Update, Delete) de usuários.

Descrição

Projeto front-end leve em HTML, CSS e JavaScript que permite listar, adicionar, editar e remover usuários. Ideal para estudos e exemplos rápidos sobre manipulação de DOM e armazenamento local.

Como usar

- Abra o arquivo `index.html` no navegador; ou
- Rode um servidor local simples (ex.: `npx http-server` ou `python -m http.server`) e acesse `http://localhost:8080`.

Recursos

- Listar usuários
- Adicionar usuário
- Editar usuário
- Remover usuário
- Armazenamento simples (localStorage)

Tecnologias

HTML • CSS • JavaScript
